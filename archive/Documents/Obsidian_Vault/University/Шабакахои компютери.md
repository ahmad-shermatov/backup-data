Мавзуъ: Оператори break ва continue
Оператори break ва continue равиши идоракунии барномаро тагйир медихад. Агар оператори break дар сохторхои while, for, do/while ё switch истифода шавад, хангоми ичрошави оператори номбаршуда, зуд кадшавии сохтори барномаро ба амал меорад. Одди карда гуем, вазифахои оператори б тез катъ намудани ягон сохтор мебошад. Масъалан, дар расми 1. дида мешавад, ки оператори даврии for истифода шудааст. Вазифаи барномаи мазкур пайдарпай ба чоп баровардани киматхои 1 то 10 аст. 
Дар дохили давр вазифаи оператори if аз он иборат мебошад, ки агар x = 5 шуд, оператори break - ро бакор медарорад ва ин оператор кори даврро катъ менамояд.

for (x = 1: x<= 10; x++) {
	if (x==5) {

		}
		Memol->Lines->Add(IntIntToStr(x));
		}
		Memol->Lines->Add("Хангоми х=5 будан, барнома кат карда шуд");
}
