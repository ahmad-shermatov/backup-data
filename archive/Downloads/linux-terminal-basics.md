## 1. Терминал

Терминал — это текстовый интерфейс для взаимодействия с операционной системой вашего компьютера посредством вводимых команд.

Используйте `echo` для вывода текста в терминале:

```bash
echo "Hello World!"
```

---

## 2. Команда echo и структура команды

Команда `echo` выводит текст на экран:

```bash
echo "Hello World!"
```

Структура команды терминала:

```bash
command "argument"
```

- `command` — программа для запуска
- `argument` — входные данные, передаваемые команде

> [!note]
> Терминал чувствителен к регистру.

---

## 3. Комментарии

Комментарии в shell-скриптах начинаются с `#` и игнорируются оболочкой:

```bash
# Это комментарий
echo "Hello!"  # Встроенный комментарий
```

**Шебанг** — специальный комментарий в начале скрипта, указывающий, какую оболочку использовать:

```bash
#!/bin/bash
```

Комментарии можно использовать, чтобы объяснять код, временно отключать команды или отмечать будущие задачи с помощью `TODO`.

---

## 4. pwd

Команда `pwd` (print working directory — «вывести рабочий каталог») показывает полный путь к вашему текущему местоположению в файловой системе:

```bash
pwd
```

Пример вывода:

```
/home/yourname
```

Разбираемся в путях:

- `/` — корень всей файловой системы
- `/home` — папка, в которой находятся домашние каталоги пользователей, например `/home/yourname`
- `/home/documents` — папка `documents` внутри `/home`

---

## 5. ls

Команда `ls` выводит список файлов и папок в текущем каталоге:

```bash
ls
```

Часто используемые параметры:

| Команда  | Что делает                                           |
| -------- | ---------------------------------------------------- |
| `ls -l`  | подробный список (права доступа, размер, дата)       |
| `ls -a`  | все файлы, включая скрытые (начинающиеся с `.`)      |
| `ls -la` | оба параметра вместе (подробный список всех файлов)  |

Чтобы вывести содержимое определённой папки, не переходя в неё:

```bash
ls folder_name
```

---

## 6. cd

Команда `cd` расшифровывается как **Change Directory** и используется для навигации между папками:

```bash
cd documents
```

Распространённые сокращения:

| Команда | Что делает                                       |
| ------- | ------------------------------------------------ |
| `cd ..` | на один уровень вверх, в родительский каталог    |
| `cd ~`  | в домашний каталог                               |
| `cd /`  | в корневой каталог                               |
| `cd -`  | вернуться в предыдущий каталог                   |

> [!tip]
> Сочетайте `cd` с `ls` и `pwd`: просматривайте содержимое, меняйте каталоги и проверяйте своё местоположение.

## 7. Абсолютный и относительный путь

**Абсолютный путь** начинается с корня (`/`) и всегда указывает на одно и то же расположение:

```bash
cd /home/documents
```

**Относительный путь** начинается с текущего каталога:

```bash
cd documents
```

Специальные символы:

- `.` — текущий каталог
- `..` — родительский каталог (на один уровень выше)

```bash
cd ./documents   # то же самое, что: cd documents
cd ..            # перейти на один уровень выше
```

---

## 8. Корневой и домашний каталог

**Корневой каталог** — верхний уровень всей файловой системы, обозначается `/`:

```bash
cd /
```

**Домашний каталог** — ваше личное пространство, обозначается `~`:

```bash
cd ~
```

Вернуться домой можно и через `cd` без аргументов:

```bash
cd
```

Ключевые различия:

- `/` — корень всей системы (общий для всех)
- `~` — ваш личный домашний каталог (обычно `/home/username`)

Проверить, на что указывает `~`:

```bash
echo ~
```

## 9. touch

Команда `touch` создаёт новый пустой файл:

```bash
touch hello.txt
```

Несколько файлов одновременно (имена через пробел):

```bash
touch file1.txt file2.txt file3.txt
```

Файл в определённом каталоге:

```bash
touch documents/notes.txt
```

> [!note]
> Если файл уже существует, `touch` обновляет время его последнего изменения, не перезаписывая файл.

## 10. cat

Команда `cat` отображает содержимое файла:

```bash
cat filename.txt
```

Другие команды для просмотра файлов:

- `head` — первые 10 строк файла
- `tail` — последние 10 строк файла
- `less` — просмотр с прокруткой (нажмите `q`, чтобы выйти)

Опция `-n` задаёт количество строк:

```bash
head -n 5 filename.txt
tail -n 3 filename.txt
```

---

## 11. cp — копирование файлов

Команда `cp` копирует файлы или каталоги.

Базовый синтаксис:

```bash
cp source destination
```

```bash
cp readme.txt backup.txt              # копия под новым именем
cp readme.txt documents/              # копия в каталог
cp -r documents backup_documents      # рекурсивное копирование каталога
cp -i readme.txt backup.txt           # спросить перед перезаписью
```

---

## 12. mv — перемещение файлов

Команда `mv` перемещает или переименовывает файлы.

Базовый синтаксис:

```bash
mv source destination
```

```bash
mv readme.txt info.txt                # переименовать
mv readme.txt documents/              # переместить в каталог
mv readme.txt documents/info.txt      # переместить и переименовать
```

> [!note]
> `mv` не сохраняет исходный файл. Команда перемещает его, а не копирует.

Флаг `-i` запрашивает подтверждение перед перезаписью существующих файлов:

```bash
mv -i readme.txt documents/
```

---

## 13. rm — удаление файлов

Команда `rm` навсегда удаляет файлы из файловой системы:

```bash
rm readme.txt
```

Удаление нескольких файлов:

```bash
rm file1.txt file2.txt file3.txt
```

Удаление каталога и его содержимого (флаг `-r`, рекурсивно):

```bash
rm -r documents
```

Флаги безопасности:

- `-i` — запрашивает подтверждение перед удалением
- `-f` — удаляет принудительно, без запросов

```bash
rm -i readme.txt
rm -f readme.txt
```

> [!warning]
> Файлы, удалённые с помощью `rm`, удаляются навсегда, и их невозможно восстановить.

## 14. mkdir

Команда `mkdir` создаёт новый каталог:

```bash
mkdir projects
```

Несколько каталогов:

```bash
mkdir projects documents backups
```

Вложенные каталоги с флагом `-p`:

```bash
mkdir -p projects/app/src
```

Флаг `-p` автоматически создаёт все родительские каталоги, если они не существуют.

**Соглашения об именовании** — используйте дефисы или подчёркивания вместо пробелов:

```bash
mkdir my-project    # ✅ хорошо
mkdir my_project    # ✅ хорошо
mkdir my project    # ❌ создаёт две папки
```

---

## 15. Копирование каталогов

Чтобы скопировать каталог со всем содержимым, используйте `cp` с флагом `-r`:

```bash
cp -r source destination
cp -r documents documents_backup
```

Если целевой каталог уже существует, исходная папка будет помещена внутрь:

```bash
cp -r documents projects/
```

Это создаст `projects/documents` со всем исходным содержимым.

> [!note]
> При копировании каталогов флаг `-r` обязателен. Без него `cp` выдаст ошибку.

---

## 16. Перемещение каталогов

Команда `mv` работает с каталогами так же, как с файлами:

```bash
mv source destination
```

```bash
mv documents files               # переименовать
mv documents projects/           # переместить
mv documents projects/files      # переместить и переименовать
```

> [!note]
> В отличие от `cp -r`, `mv` не оставляет исходный каталог — она перемещает его целиком.

---

## 17. Удаление каталогов

Удалить пустой каталог:

```bash
rmdir empty_folder
```

Удалить каталог со всем содержимым:

```bash
rm -r documents
```

Удалить принудительно, без подтверждений:

```bash
rm -rf documents
```

> [!danger]
> `rm -rf` навсегда удаляет всё без запроса, и это нельзя отменить.

## 18. Подстановочный знак *

**Подстановочный знак** — это специальный символ, который соответствует одному или нескольким символам в именах файлов и позволяет работать с несколькими файлами одновременно.

Звёздочка `*` соответствует **любому количеству символов** (включая ноль).

```bash
ls *.txt          # все файлы, заканчивающиеся на .txt
ls photo*         # все файлы, начинающиеся с photo
ls *report*       # все файлы, в имени которых есть report
ls *              # все файлы
cp *.jpg photos/  # скопировать все .jpg в папку
rm *.log          # удалить все .log
```

> [!tip]
> Всегда сначала выполняйте `ls` с шаблоном, прежде чем использовать его с `rm` или `mv`, чтобы увидеть, какие файлы будут затронуты.

---

## 19. Подстановочный знак ?

Вопросительный знак `?` соответствует **ровно одному символу**. В отличие от `*`, который соответствует любому количеству символов, `?` точнее: каждый `?` — это одна позиция.

Файлы с ровно одним символом после `file`:

```bash
ls file?.txt
```

Несколько `?` подряд:

```bash
ls file??.txt   # file10.txt, file23.txt и т. д.
```

Сочетание с другими символами:

```bash
ls ???.txt      # любой .txt-файл с именем ровно из 3 символов
ls img_?.jpg    # img_1.jpg, img_2.jpg, но НЕ img_10.jpg
```

**Когда что использовать:**

- `?` — когда вы точно знаете, сколько символов меняется
- `*` — когда количество меняющихся символов неизвестно

---

## 20. Квадратные скобки []

Шаблон `[]` соответствует **ровно одному символу** из набора или диапазона внутри скобок.

Конкретные символы:

```bash
ls file[123].txt    # file1.txt, file2.txt, file3.txt
```

Диапазоны:

```bash
ls file[1-3].txt    # цифры от 1 до 3
ls file[a-z].txt    # любая строчная буква
ls file[A-Z].txt    # любая заглавная буква
ls file[0-9].txt    # любая одна цифра
```

Отрицание — `!` или `^` в начале, чтобы исключить символы из набора:

```bash
ls file[!45].txt    # всё, кроме file4.txt и file5.txt
ls file[^45].txt    # тот же результат
```

Объединение наборов:

```bash
ls file[1-3a-c].txt    # file1, file2, file3, filea, fileb, filec
```

## 21. Комбинирование подстановочных знаков

`*`, `?` и `[]` можно объединять для точных шаблонов.

`*` и `{}` / `[]`:

```bash
ls *.{jpg,png}    # раскрытие фигурных скобок для нескольких расширений
ls *.[jp]*        # расширения, начинающиеся на j или p: .jpg, .jpeg, .png, .pdf и т. д.
```

`?` и `[]`:

```bash
ls photo_[0-9].jpg   # только фото с однозначным номером
```

Все три вместе:

```bash
ls *_[0-9].txt     # имя заканчивается на _, одну цифру и .txt
ls [pr]*_?.txt     # начинается с p или r, затем любые символы, _, один символ и .txt
```

С другими командами:

```bash
mv photo_[0-9].jpg archive/   # переместить фото с однозначным номером
rm */*.log                    # удалить .log из любой подпапки
```

## 22. head и tail

`head` показывает первые строки файла (по умолчанию 10):

```bash
head log.txt
```

`tail` показывает последние строки файла (по умолчанию 10):

```bash
tail log.txt
```

Флаг `-n` задаёт количество строк:

```bash
head -n 3 log.txt   # первые 3 строки
tail -n 1 log.txt   # последняя строка
```

Посмотреть начало и конец файла:

```bash
head -n 2 log.txt
tail -n 2 log.txt
```

## 23. wc

Команда `wc` подсчитывает строки, слова и байты в файле:

```bash
wc notes.txt
```

```
  5  26  154 notes.txt
```

- первое число — строки
- второе — слова
- третье — байты

Флаги для подсчёта конкретных элементов:

```bash
wc -l notes.txt   # только строки
wc -w notes.txt   # только слова
wc -c notes.txt   # только байты
wc -l *.txt       # строки во всех .txt-файлах
```

> [!note]
> `wc -l` считает символы новой строки. Если последняя строка не заканчивается переводом строки, результат будет на единицу меньше ожидаемого.

## 24. sort

Команда `sort` упорядочивает строки файла в алфавитном или числовом порядке:

```bash
sort filename.txt
```

Полезные флаги:

| Флаг    | Что делает                                       |
| ------- | ------------------------------------------------ |
| `-r`    | обратный (убывающий) порядок                     |
| `-n`    | числовая сортировка (по значению)                |
| `-u`    | сортировка с удалением повторов                  |
| `-k n`  | сортировка по n-му столбцу                       |

```bash
sort -r filename.txt
sort -n numbers.txt
sort -u filename.txt
sort -k2 data.txt
```

> [!note]
> `sort` не изменяет исходный файл, а только выводит отсортированный результат на экран.

## 25. uniq

Команда `uniq` отфильтровывает **идущие подряд** повторяющиеся строки. Она удаляет только соседние повторы, поэтому обычно сначала используют `sort`:

```bash
sort duplicates.txt | uniq
```

Символ `|` — это **канал** (pipe). Он передаёт вывод одной команды на вход другой.

Полезные флаги:

```bash
sort duplicates.txt | uniq -c   # количество повторений перед каждой строкой
sort duplicates.txt | uniq -d   # только повторяющиеся строки
sort duplicates.txt | uniq -u   # только строки, встречающиеся ровно один раз
```

## 26. grep

`grep` расшифровывается как **Global Regular Expression Print**. Это одна из самых мощных и часто используемых команд терминала. Она ищет в файлах и выводит каждую строку, содержащую шаблон (pattern).

Пример файла `server.log`:

```
info: server started
info: listening on port 8080
error: disk full
warning: high memory usage
info: request received
error: connection timeout
info: server shutdown
```

Базовый формат:

```bash
grep "pattern" filename
```

Найти все строки со словом `error`:

```bash
grep "error" server.log
```

Вывод:

```
error: disk full
error: connection timeout
```

Выводятся только строки, содержащие `error`. Все остальные скрыты.

Поиск в нескольких файлах:

```bash
grep "error" *.log   # искать во всех .log-файлах
```

Поиск фразы с пробелами:

```bash
grep "connection timeout" server.log
```

**Чувствительность к регистру.** По умолчанию `grep` учитывает регистр, поэтому `error` не найдёт `Error` или `ERROR`:

```bash
grep "error" server.log    # совпадает: error
grep "Error" server.log    # совпадает: Error
grep "ERROR" server.log    # совпадает: ERROR
```
