Терминал	Текстовый интерфейс для взаимодействия с ОС с помощью вводимых команд
echo "текст"	Выводит текст на экран
Структура команды	command "argument": программа + входные данные для неё
Чувствителен ли терминал к регистру?	Да: ls и LS — разные команды
#	Начало комментария, оболочка его игнорирует
#!/bin/bash	Шебанг: указывает, какую оболочку использовать для скрипта
pwd	Показывает полный путь к текущему каталогу (print working directory)
ls	Выводит список файлов и папок в текущем каталоге
ls -l	Подробный список: права доступа, размер, дата
ls -a	Все файлы, включая скрытые (начинаются с .)
ls -la	Подробный список всех файлов, включая скрытые
cd folder	Перейти в папку folder (Change Directory)
cd ..	Перейти на один уровень вверх, в родительский каталог
cd ~	Перейти в домашний каталог
cd /	Перейти в корневой каталог
cd -	Вернуться в предыдущий каталог
cd (без аргументов)	Перейти в домашний каталог
Абсолютный путь	Путь от корня /, например /home/documents
Относительный путь	Путь от текущего каталога, например documents
. (одна точка)	Текущий каталог
.. (две точки)	Родительский каталог
/	Корень всей файловой системы (общий для всех)
~	Домашний каталог пользователя, обычно /home/username
echo ~	Показывает, на какой путь указывает ~
touch file.txt	Создаёт пустой файл (или обновляет время изменения существующего)
touch a.txt b.txt	Создаёт несколько файлов сразу
cat file.txt	Показывает содержимое файла
less file.txt	Просмотр файла с прокруткой, q — выход
cp a.txt b.txt	Копирует файл a.txt в b.txt
cp -i	Копирование с запросом перед перезаписью
cp -r src dst	Рекурсивно копирует каталог со всем содержимым
Что будет, если копировать каталог через cp без -r?	Ошибка
mv old.txt new.txt	Переименовывает файл
mv file.txt dir/	Перемещает файл в каталог
mv file.txt dir/new.txt	Перемещает и переименовывает файл
mv -i	Перемещение с запросом перед перезаписью
Сохраняет ли mv исходный файл?	Нет, mv перемещает, а не копирует
rm file.txt	Навсегда удаляет файл
rm -i	Удаление с запросом подтверждения
rm -f	Принудительное удаление без запросов
rm -r dir	Удаляет каталог со всем содержимым
rm -rf dir	Удаляет каталог со всем содержимым без запросов, отменить нельзя
rmdir dir	Удаляет только пустой каталог
mkdir dir	Создаёт новый каталог
mkdir -p a/b/c	Создаёт вложенные каталоги вместе с родительскими
mkdir my project	Создаёт ДВЕ папки: my и project (ошибка из-за пробела)
* (звёздочка)	Подстановочный знак: любое количество символов, включая ноль
ls *.txt	Все файлы, заканчивающиеся на .txt
ls photo*	Все файлы, начинающиеся с photo
ls *report*	Все файлы, в имени которых есть report
Что делать перед rm или mv с шаблоном?	Сначала выполнить ls с тем же шаблоном и проверить файлы
? (вопросительный знак)	Подстановочный знак: ровно один символ
ls file??.txt	Файлы вида file10.txt, file23.txt (ровно 2 символа)
ls img_?.jpg	img_1.jpg, img_2.jpg, но НЕ img_10.jpg
Когда использовать ?, а когда *?	? — когда точно знаешь количество символов, * — когда не знаешь
[abc]	Ровно один символ из набора a, b или c
file[1-3].txt	file1.txt, file2.txt, file3.txt
[a-z]	Любая одна строчная буква
[0-9]	Любая одна цифра
[!45] или [^45]	Любой один символ, кроме 4 и 5
file[1-3a-c].txt	file1, file2, file3, filea, fileb, filec
*.{jpg,png}	Раскрытие фигурных скобок: все .jpg и .png
rm */*.log	Удаляет .log-файлы из любой подпапки
head file	Первые 10 строк файла
tail file	Последние 10 строк файла
head -n 3 file	Первые 3 строки файла
tail -n 1 file	Последняя строка файла
wc file	Считает строки, слова и байты (в этом порядке)
wc -l	Считать только строки
wc -w	Считать только слова
wc -c	Считать только байты
Почему wc -l может показать на 1 меньше?	Последняя строка не заканчивается символом новой строки
sort file	Сортирует строки по алфавиту
sort -r	Сортировка в обратном (убывающем) порядке
sort -n	Числовая сортировка (по значению)
sort -u	Сортировка с удалением повторов
sort -k2	Сортировка по второму столбцу
Изменяет ли sort исходный файл?	Нет, только выводит результат на экран
uniq	Удаляет повторяющиеся строки, но только идущие подряд
Почему перед uniq обычно ставят sort?	uniq удаляет только соседние повторы, sort ставит их рядом
| (pipe, канал)	Передаёт вывод одной команды на вход другой
uniq -c	Показывает количество повторений перед каждой строкой
uniq -d	Только повторяющиеся строки
uniq -u	Только строки, которые встречаются ровно один раз
grep	Global Regular Expression Print: ищет строки с шаблоном
grep "error" server.log	Выводит все строки server.log, содержащие error
grep "error" *.log	Ищет error во всех .log-файлах
Учитывает ли grep регистр по умолчанию?	Да: "error" не найдёт Error или ERROR
